# D68 · 把 PAD 项目页做成演示稿的样子

用户："做成你给我演示html的那样。"

对照稿：`00-reference-demo.png`（把 D67 的 demo-live.html 从提交 `2b51343` 取回后重新渲染的截图）。
实现：`01-project-page.png`（真 PAD 窗口，PrintWindow 抓取）。

## 改了什么（只动项目页排版，不动功能）

1. **卡片高度跟内容走**：项目页不再用固定 226 高的 `ScopeCard`，新增 `ProjectCard`（宽度仍 280/576/864，
   MinHeight 120，其余同一套 WbCard 样式/悬停/进场）；卡片底部不再留一整块空白。
2. **启动卡**：统计 2×3 不变；动作从右侧竖排改成**统计下面横排一行**，顺序和演示稿一致：
   `打开对话（主色）· 打开界面 · 打开工作区 · 实例视角`；没在跑时第一个按钮变成 `启动`。
   `打开界面` 优先用账本 URL，没有就退到实例日志里最近一次 `dsh web:` 的 token URL。
3. **三张卡一排**：`agent preset · 工作区 · 对话`，高度随内容；对话卡保持「大数字 + 点一行直接打开 + 打开 DSH 窗口」。
4. **环境卡**：从整行六格改成 **1 列 2×2**（内核/组合包/会话/整合包），和演示稿一致。
5. **侧栏搜索框占位文案**：`搜索项目（按名字过滤）`，只在项目视角出现。

没动的：PAD 顶部导航、侧栏分组/搜索逻辑、主页/实例页、所有按钮背后的真实动作（启动/停止/打开对话/
preset chip/编辑菜单/实例↔项目跳转全部沿用已有实现）。
