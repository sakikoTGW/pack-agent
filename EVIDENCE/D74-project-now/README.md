# D74 · 打开项目 = 这个项目的「现在」

用户：「每个项目打开应该是类似左边的」——指原型 v4 左边 PAD 面板的「现在」页
（三格计数 + 等你输入/在跑/刚完成 三段流 + hover 预览）。收编已按 D73 砍掉，不在。

## 改了什么
- `PaintProjectCards` 不再是卡片堆（智能体团队/工作区/任务/能力/最近会话/配置），
  改成和全局「现在」同一套组件：**三格计数 + 三段流**；
- 数据：`LoadProjectAsync` 加载 `CollectProjectNow(proj)` —— 只读该项目实例 home 的投影缓存，
  且只留 cwd 落在项目 `Workspaces` 里的会话；
- hover 预览、彩色项目块沿用全局现在页那套；
- 点项目里的会话行 = 聚焦该项目的 DSH 窗口（`OpenProjectWindow`）；
- 项目没有会话时显示一张空态卡：「点右上角『去启动』跑一次…」，不装成有数据。

- `01-now-global.png`：全局现在（只有一个项目 ev-project）
