## 验收发现（按严重度）
1. **实例列表没有运行状态**：管理页左栏只有名字+版本，看不出哪个在跑（launch 页才写"有实例在跑"）。
2. **术语分裂**：管理页叫「组合包」，实例页叫「整合包」，同一个东西两个词 → 用户不知道是不是一回事。
3. **装包入口有两个、互不相通**：管理页的「添加」要输 npm 包名/本地路径（开发者向）；实例页才有「装整合包…」（文件导入）。普通用户找不到该从哪装。
4. **启动页信息重复且空**：左栏选中实例卡 + 右栏又画一遍同一个实例的图标/版本，右栏 90% 是空白；主操作只有「启动」，没有「已在跑→打开窗口」。
5. **设置页细节破损**：「命令覆盖」长路径文字被输入框裁切；「使用本机 DSH/选择 DSH/选择 dsh-tui」三个按钮语义不清。
6. 管理页右侧大片空白；「正在聊的」区域没有内容时显得像坏了。
