# D80 · 启动器修复（术语统一 / 实例状态 / 正在聊的 / 装包入口 / 设置裁切）

用户：「现在开始只有整合包。实例加入运行状态。管理页『正在聊的』修复。3，5修复」。

## 改了什么
1. **术语统一**：PAD 里所有用户可见的「组合包」→「整合包」（Views/Core/CLI 空状态），
   代码标识符不动；`empty-state.ts` 同步。测试里断言旧文案的一处改成新文案。
2. **实例列表加运行状态**：`ManageView` 实例行右边显示「在跑/已停」（在跑=accent 色）；
   列表改为 `InstRow`（Name/Version/StateText/Live），选中的实例仍写回全局。
3. **管理页『正在聊的』修复**：
   - 实例没启动 → 「这个实例还没启动。启动后这里会列出正在跑的 agent 会话。」
   - 启动了但没有管理口 → 「这份实例没有管理口，看不到正在聊的会话。」
   - 运行中但没会话 → 「还没有正在聊的会话」；
   - 不再把「整合包更新不需要管理口」这种串场文案塞进会话区。
4. **装包入口**：管理页「整合包」区新增「装整合包…」按钮（与实例页同一套 file→Packs.Project 流程），
   npm 输入框占位改成「整合包（npm 包名 / 本地路径）」。
5. **设置页裁切**：「命令覆盖」下面补一行等宽只读完整路径（跟随输入框），长路径不再只靠一个 28px 输入框吞掉。
