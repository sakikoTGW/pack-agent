# D84 · 插件行：可更新更醒目，第二行改成简介

用户指出（版本设置 → 插件）：
1. 「可更新」不明显；
2. 第二行显示的是安装路径，应该是插件简介。

## 改动
- **可更新**：行内加实色徽标「↻ 0.28.0 → 0.28.2」（Accent 底 + 白字），右侧直接给实心「更新」按钮；
  不可更新的行只保留灰色刷新小图标；顶部「可更新 (N)」筛选不变。普通标签里不再塞「可更新」。
- **第二行 = 简介**：`PluginRow.SubLine` 改为 description；包没写简介显示「包里没写简介。」，不再拿
  `PackageDir` 顶替（路径仍在「打开插件目录」按钮/详情里）。
- 顺带修：收编实例（本机 DSH）在「版本设置 → 插件」里显示"这份实例还没有 profile"——profile 下拉在
  `Launchables` 为空时回退到 `home/profiles`（通用，不写死实例），现在 desktop 的 12 个插件能列出。

## 实拍
`05-plugin-page.png`：本机 DSH · 插件页 全部(12) / 可更新(8)，可更新行有版本徽标 + 更新按钮，
第二行是简介（dsh-better-sidebar 等处可见），无简介显示「包里没写简介。」。

## 验证
build 0 warning / 0 error；pad-window / pad-pack 绿。
