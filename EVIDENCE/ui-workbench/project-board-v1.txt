项目面板（单个 DSH 的内部架构）— 视觉 v1 (2026-10-23)

层级理解
  本机主页      本机所有 DSH 的方形卡片（人自己插）
  每个 DSH      自己的面板：这个项目被切成的区块
  区块          一个目录 + 落在里面的若干 agent
  agent         一条会话（DSH 的 session）

映射到 DSH 既有概念（不发明新东西）
  一个 DSH 实例 = 一个项目 = 一份 DSH_HOME + 一个工作区
  区块 = 工作区下的一个子目录（物理分层，agent 的 cwd 天然隔离）
  agent = 该目录里的一条会话
  "创建 agent" = 在该目录新建一条会话

用词
  DSH 里没有"派发"——会话是创建出来的，任务才是派发的。
  UI 用「创建」，磁盘上仍是 session。等真做任务版再引入"派发"。

图中有一个我自己的越界，必须指出来
  区块卡上画了"3/8"这种任务进度条 —— 但 D18 定过 PAD 不做任务/验收，
  画进度就等于替人判断"做完了多少"。应改为：活跃会话点阵 + 最近活动时间，
  或者干脆只有 agent 点阵。这一版先留在图里当反例。
