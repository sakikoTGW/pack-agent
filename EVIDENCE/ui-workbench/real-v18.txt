层级收敛：默认折叠 + 点击展开 (2026-10-25)

默认状态（第一眼）
  展开：工作区 → 实例
  折叠：实例下的 agent   -> 徽标 "+N"（本机 DSH 显示 +10，右侧另有 1 子）
  一眼只有 7 张卡，注意力不被 11 条会话冲散

点击行为
  点带徽标的卡 -> 展开/收起该节点，整棵树重新布局并自动重新适配窗口
  展开后显示 "−"，可再收起
  展开状态按视图 id 记住（切到"按项目"再回来，仍是展开的）

缩放策略（改过一次）
  折叠时节点少 -> 自然尺寸可读
  手动全展开 -> 整体等比缩小，保证一屏看全；细节靠拖拽/滚轮（d3.zoom）

验证
  --shot-page relations-sessions            默认折叠态
  --shot-page relations-sessions-expanded   强迫全展开（调用 window.expandAll()）

未做

  展开动画：现在是重绘，没有过渡
