操作收进侧栏 (2026-10-25)

侧栏现在是树，也是唯一操作入口
  工作区  ▸/▾  展开出实例
  实例    ▸/▾  展开出 agent
  agent       只显示（父会话与子会话数在 meta 里）
  点箭头 = 改展开状态；状态写 ui-state.json；图跟着变

两侧同步
  侧栏改 -> UiState.Save -> ExecuteScriptAsync(setOpen(ids))
  图里点徽标 -> postMessage -> UiState.Save -> 重建侧栏
  同一份状态，两个视图，不会打架

图这边
  徽标暂时保留（旧路径），等确认侧栏够用后可以撤掉，图就退化成纯展示

  （聚焦），而不是把整棵树塞进窗口。
