聚焦 + 图上只留摘要 (2026-10-25)

聚焦
  侧栏点行体 = 聚焦：图只画这一支（不是整棵森林）
  箭头 = 展开；行体 = 聚焦。两个动作分开
  聚焦状态存 ui-state.json 的 Focus，重启后仍在

图上限制扇出
  每个节点最多画 6 个子节点，其余收成一张 "+N 个（看侧栏）" 占位卡
  理由：11 条会话并排会把整张图缩到看不清；图负责结构概览，完整列表在侧栏

尺寸
  卡片 276/236/186/186，节点间距 214×140 —— 让 6 个孩子能在 920 宽里可读

踩坑（值得记）
  PowerShell 的可变 here-string @" "@ 会吃掉 Python 代码里的双引号，
  导致写出的 JS 里 id + "." + i 变成 id + . + i，整页白屏。
  教训：写含引号的代码一律用 @' '@（字面）或 edit 工具，不要用 @" "@。
