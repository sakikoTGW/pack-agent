管理首页 v3 — 侧栏 + 可自排卡片 (2026-10-24)

侧栏
  列出全部项目（实例）；运行中的点用强调色，其余灰
  选中项底色高亮；可收起 232 <-> 64，收起后只留首字与状态点

卡片区
  5 种卡：在运行(环) / 已收录(数+点阵) / 上下文(水位) / 项目卡(绑定实例) / 便签(文字)
  存 pad.json#ui.cards；数组顺序 = 页面顺序；空数组时自动给默认三张
  「编辑」进入编辑态：每张卡右上角 ×（删除），末尾出虚线 + 卡
  「+ 卡片」随时可开菜单加入新卡

本轮验证的方式（点不到按钮，就用等效手段）
  直接往 pad.json 写入 4 张自定义卡片：
    project(source=123) / note / context / running
  重开后页面严格按这 4 张渲染，顺序一致 —— 说明"编排存在磁盘上"这条成立。

修掉的一个样式问题
  便签卡原本用 TextBox，被全局输入框样式套上一个圆角边框，看着像表单。
  改为：查看态用 TextBlock（纯文字），编辑态才换成 TextBox。
