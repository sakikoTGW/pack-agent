管理首页 v6 — 提高信息密度 (2026-10-24)

用户否决 v5 的理由：削减复杂度可以，但不能把信息密度一起削掉。
改法：每张卡承载 2-3 层，全部用形状，不加说明文字。

在运行   环 = 在跑/全部；下方每 home 一根柱，高度=会话数，实心=在跑
已收录   大数字 + 热力方块：深浅=会话量，实心色=在跑
上下文   竖水位(窗口占用) + 百分比 + 横条(工具定义占上下文的多少)
近 7 天  柱状 + 逐日标签
工具调用 每行两层：上柱=调用次数，下柱=该工具消耗的 token

两条做法（D30）
  缺席也要画：空闲 home 给最小柱（+1 归一），否则版面显空
  一条柱两维度：次数 + token，比多开一张卡省地方

踩到的三个坑
  1 共享的 DropShadowEffect 是冻结对象，hover 里改 Opacity 会抛异常 -> 每张卡建自己的实例
  2 卡片固定高 226，柱子 Bottom 对齐后被卡片底边裁掉 -> 缩小环到 104，strip 降到 34
  3 空闲色用 LineDivider 在白卡上几乎不可见 -> 改用 LineBorder

数据：工具调用 780 次（pwsh 558 / edit 106 / read 61 / read_image 34 / write 21）
