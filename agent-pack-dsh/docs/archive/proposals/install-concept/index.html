整合包「安装」概念 · 前端原型

三张可点开的原型，对应提案里的三个界面：①版本页补「安装」动作 ②实例页从包库装 + 预检徽标 ③预检/一次授权/安装报告。
尺寸与真实 PAD 窗口一致（1500×930），深顶栏 + 浅灰卡片沿用现有主题。
原型 1 / 3

版本选择页：整合包行补「安装 ▾」

安装 = 装到当前选中实例（推荐）；菜单保留 PCL 式「新建实例」。版本页仍不写"装到哪"。
原型 2 / 3

实例页：装整合包 = 从本机包库选

包库列表带图标与预检徽标（✅可装 / ⚠需授权 / ⛔已下架 / 已装可修复），目标实例写在标题上。
原型 3 / 3

预检 · 一次授权 · 安装报告

装之前把内核/下架/需授权/版本冲突一次列清，一次勾选；装完给新增/豁免/跳过/失败报告，包标不完整可修复。
效果预言（一句话）
用户从包列表点「安装」→ 选目标实例 → 看到预检清单（Test 包：8 可装 / 1 需授权 / 1 已下架）→ 勾"全接受风险 + 跳过下架" → 安装报告显示 9 新增 1 豁免 1 跳过，实例页该包发光并标「不完整 · 缺 1 个」，可随时修复。
不改变的东西
版本页仍不显示"装到哪"；装态仍由实例页发光/账本药丸表达；新建实例仍是 PCL 式派生；导入/扫描/导出入口不动。
