PAD UI SPEC v1

文字纪律 · 视觉表达

能删就删；有用但吵的文字藏进层级（悬停/展开/详情）；状态用视觉表达，句子是最后手段。一个视区只让人看一件事，禁止一屏堆字。
01
能删就删

去不去掉没有任何区别的文字，直接删。删了用户不会做错事，就是噪音。

02
有用但吵 → 藏

不要常驻。用 Tooltip / 展开详情 / 报告承载；常驻只留此刻要决定的那一句。

03
视觉即语义

图标 > 颜色 > 药丸 > 短标签 > 句子。不读字也要能看懂发生了什么。

04
一次一件事

一个视区/弹窗只有一个主信息层级；一屏最多 1 句主提示。

05
同类统一

同一概念全局同一套 icon/颜色/组件；禁止自创，尤其禁止用大文字当图标。

版本页装态「已装到 sisyphus · 已建实例 X」文字药丸常驻删掉；装态回实例页（发光 + 账本药丸），版本页只回答"这是什么包"
无图标回落用字符「包」做成 pill 当图标统一包图标；缺图时用同尺寸 fallback 图标，不用文字
