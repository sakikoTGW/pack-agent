D动效与反馈

▾
hover / focus · 120ms鼠标移上去：颜色/边框变化，不位移
●
呼吸 · 1.6s loop全局唯一"活着"语义：运行中 / 已启用
场景时长 / 曲线备注
hover / focus120ms ease-out只改颜色/阴影，不缩放布局
状态切换 / 行插入删除160–200ms ease-out不弹跳、不整页闪
菜单 / 弹窗出现180ms ease-out + 8px 上移淡入；关闭可更快（120ms）
长任务（>400ms）阶段推进预检 → 授权 → 安装 → 报告，同窗推进
每个操作必须有反馈：按下态 → 进度 → 结果 →（失败）原文 + 重试。禁止静默。

EPR 检查清单（10 条）

1常驻文字删到 ≤1 句主提示 / ≤1 行辅助？
2技术原文都进了 Tooltip / 展开 / 报告？
3状态用视觉（药丸/颜色/图标）而不是句子？
4图标都来自同一套，没有文字作图？
5同类组件尺寸/圆角/状态色与其他页一致？
6默认值顺手（目标实例、菜单第一项、Enter/Esc）？
7每个操作有反馈，失败可读可重试？
8动效 120–200ms，且呼吸只有一个语义？
9一屏只让人看一件事？
10动词/状态词全局一致，没有同义词混用？
