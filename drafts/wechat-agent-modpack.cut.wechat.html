AGENT MODPACK

换个壳，
半个月配置就像没配过

像装 MC 整合包一样，装你的 agent。

练习结束了。睦抱着吉他站在门口。

祥子没叫她留下谈乐队。笔记本亮着，资源管理器开着一个几乎空的文件夹，只有一份 packer.pack.json。

祥子：睦。看一下这个。别走。

睦：……嗯。

祥子：我把 Cursor 里用顺的那套——skills、规则、还有 MCP——整夹拷进 Codex。文件在。我问它看不看得到「agent-pack」。

它说没有。

睦：……在，却没有。

祥子：Cursor 认一套目录，Codex 认另一套。我塞错层了。MCP 更烦，装的时候点几下，卸的时候凭感觉删，删完半残。

半个月配的东西，换个壳，就像没配过。

睦：……像……换场地……线乱了。

祥子：……对。玩 MC 的人不会靠拖 mods 文件夹换启动器。他们用整合包：一份文件，装得上，卸得掉，换启动器还能落到对的位置。

祥子：我就做了这个。Agent Modpack。

https://github.com/sakikoTGW/pack-agent

npm：@sakikotgw/pack-agent（Bun ≥ 1.1）

把「一个角色」打成一份 .pack.json。

角色不是人格——是 agents.yaml 里点名的那组 skills、规则、MCP。

install 写进壳，eject 按账本删。换壳时 adapter 改路径，不用手改。

点名 → 打包 → 投射；右边是账本

祥子：本机有哪些壳，先看一眼。

detect

睦：……好几家。

祥子：嗯。先看一家。空目录，只放这份包，装进 Codex：

npx --yes -p @sakikotgw/pack-agent packagent install .\packer.pack.json --runtime codex

装完：.agents/skills 里出现 agent-pack

祥子：文件在了不算。我当面问它——

能看到，agent-pack 这个 skill 是用来把 skills、rules、MCP、harness prompts 等内容打包/导出/同步成可移植的 agent 包，也可以安装到不同的 Codex/Claude Code 环境里。

睦：……这次……认了。

祥子：再卸。

npx --yes -p @sakikotgw/pack-agent packagent eject --name packer

卸完：技能目录空了

祥子：再问同一句。忘了。

睦：……来过。……又走了。

祥子：干净。实录在 %TEMP%\packagent-codex-verify-20260719-040422。

睦：……MCP 呢。……会不会只带走一半。

祥子：角色接了工具链，MCP 和 skill 进同一份包。只拷 SKILL.md 不够。Hermes 上这份：装前两边都空。

Hermes skills 装前为空

Hermes mcp 装前无 agent-pack

npx --yes -p @sakikotgw/pack-agent packagent install .\packer-mcp.pack.json --runtime hermes --global-config

skills 出现 agent-pack

mcp 也出现 agent-pack

祥子：有了 skill + MCP，这个角色能自己调 pack_export / pack_install / pack_eject。我让它把示例角色 hello-pack 再打一份，装回去——工具包和业务包可以并排。

skills：agent-pack + hello-pack

睦：……卸一个……另一个呢。

祥子：eject --name hello-pack 只卸 hello-pack。账本按包名记账，不会目录里有东西就一锅端。

eject 后 skills

睦：……谱和效果器……一起装箱。……拿走该拿走的。

祥子：……嗯。

睦：……驯服过的脾气呢。

祥子：经验跟 skill 不是一类东西。

skills、规则、MCP 落在磁盘上，进包就能带走。
经验是对话里用顺的脾气：冲突时默认停还是盖、哪条路试过。它还会变。

写进 skill 会定死；经验却还在漂。所以经验不进 skill 树——基座可以进包，接上壳的 hook 后写入 live.json，下一轮注回上下文。

经验：不进 skill，基座 + live

祥子：同一会话两轮。第一轮只有「把 packer 迁到 Hermes」；第二轮加上「冲突时默认 stop」。注回去的内容会跟着变。

live inject · turn 1

live inject · turn 2

睦：……会变。……不是写在纸上骗自己。

祥子：还没对齐各家壳真正发给模型的那一层时，包上会标 L1，换模型更容易漂。

睦：……同名呢。……会不会盖错。

祥子：默认停。--on-conflict stop。不覆盖。

冲突：默认 stop

睦：……宁可……少删。

祥子：……对。

睦：……跟拷目录……差在哪。

祥子：拷目录：路径各家不同，卸靠手，换壳自己改。
只撕一页 SKILL.md：不管 MCP，也不管规则。
这份包：整个角色，一份文件，账本卸，adapter 投射。

睦：……一份……就够。

祥子：它不负责让你变强。模型、账单、你驯得怎样，都不在这个文件里。只负责配置还能带走。

睦：……祥。……我想摸摸看。

祥子：……好。

npm install -g @sakikotgw/pack-agent
packagent agents init
packagent export --agent <角色id>
packagent install .\.agent-pack\exports\<包名>.pack.json

祥子：先看本机能装哪几家，就 packagent detect。细则在仓库 docs/。Cursor 要显式加 --runtime cursor。

睦：……嗯。……一份包，一个角色。

祥子：下次换机器，先看账本还在不在。

睦：……好。

装得上，认得出，卸得掉；skill 和 MCP 可以一起走；经验还在会变的那一层。
